# ADR-002：TinyTroupe 只能通过适配层使用

- 状态：已接受
- 日期：2026-08-13

## 背景

TinyTroupe 为实验性项目，版本升级可能包含破坏性 API 变化。

## 决策

固定 Git 提交依赖，只有 `simulation/tinytroupe_adapter.py` 可以导入 TinyTroupe。业务 Skill 依赖项目自有协议与模型，不依赖第三方具体类型。

训练对话采用持久化世界模式：场景全部角色作为 `TinyPerson` 加入 `TinyWorld` 并接收公开事件，每轮由确定性规则选择最多 6 名角色行动。DeepSeek 通过项目桥接客户端为 TinyTroupe 提供底层推理；角色 Skill 不再调用 DeepSeek 二次生成台词。

项目规则仍拥有事实披露权限、四维状态裁剪、阶段推进和评分的最终决定权。TinyTroupe 的认知状态只能提供每轴 `±4` 的状态建议。角色回复越界时只允许在 TinyTroupe 内重试一次，失败后整轮回滚，不使用旧链路兜底。

## 后果

- 升级影响集中在单一文件。
- TinyTroupe 未安装或初始化失败时，服务仍可启动并通过健康接口报告降级状态。
- 角色推演请求明确失败，不回退已删除的旧链路。
- TinyWorld 快照由 AI 服务按训练工作流独立持久化，平台只保存正式消息和四维状态。
- 私有 `THINK` 只存在于模拟快照，不进入平台响应和审计日志。
