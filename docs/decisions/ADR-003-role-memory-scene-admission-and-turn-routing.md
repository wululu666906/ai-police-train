# ADR-003：角色隔离、场景准入与 TinyTroupe 世界发言

- 状态：已接受
- 日期：2026-08-24

## 决策

角色构建节点一次性生成身份画像、来源记忆、知识账本和四维初始值。角色只能读取固定身份、本人私有记忆、本场景当前可回答事实和公开会话；不得因姓名出现在事实文本中就获得该事实，也不得向每个角色注入完整案件剧情。

场景生成不使用默认场景、默认阶段、默认考核点或默认角色名单。候选场景必须通过对话占比、多轮交互必要性、训练收益、角色支撑度、考核可观察性和纯文本可完成度校验。首次生成不合格时只允许依据明确问题修复一次，仍无合格结果时返回空场景及原因。

对话训练的发言编排由 TinyTroupe 世界负责。在场角色全部感知公开事件，最多 6 人进入行动；各 `TinyPerson` 自行决定 `TALK` 或沉默。外部 Skill 只负责在场准入和人数上限，不再用 LLM 指定唯一说话人。合法沉默是成功结果，不得强迫任一角色发言。

四维状态中的 `emotion` 表示情绪激动度，数值越高越激动。四维值只轻微影响台词语气和组织形式，不参与发言资格、事实权限、披露范围、训练阶段或动作结果判断。

## 后果

- 正式审讯、追捕和战术行动等无法通过纯文本多轮对话稳定训练的场景不生成。
- 平台必须接受案件导入成功但场景列表为空，并展示不适训原因。
- TinyWorld 只创建本场景在场角色，公开事件共享，私有记忆保持隔离。
- 同一轮可出现多名角色公开台词；事实披露、阶段推进和评分仍由项目规则决定。
- 建议追问独立消费完整公开历史和累计考核进度，不再由平台拼接缺失项。
