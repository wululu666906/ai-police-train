# ADR-001：AI 工作流使用独立服务

- 状态：已接受
- 日期：2026-08-13

## 背景

用户要求新能力与平台完全隔离，任一侧异常不得导致另一侧不可用。旧 AI 链路已被删除且不允许作为降级路径。

## 决策

AI Agent、Skill、Tool、TinyTroupe 和 DeepSeek 适配层部署为独立 FastAPI 服务。平台只通过白名单 HTTP 客户端调用，Agent 不获取平台数据库连接。

## 后果

- 获得进程、依赖、故障和权限隔离。
- 跨服务数据必须有显式契约和幂等语义。
- Agent 故障时 AI 功能返回受控 503；平台其他功能继续工作。
