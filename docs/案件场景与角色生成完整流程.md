# 案件场景与角色生成完整流程

## 1. 案件场景生成流程

```mermaid
flowchart TD
    A[案件文件或原文] --> B[文档解析与文本清洗]
    B --> C[来源压缩与无关附录隔离]
    C --> D1[事实和人物解析]
    C --> D2[完整剧情专家生成]
    D1 --> E1[事实卡和来源引用]
    D1 --> E2[人物卡和原始证言]
    D1 --> E3[事件账本和时间空间线]
    D2 --> F[剧情覆盖核对与事件明细重建]
    E1 --> G[案件故事世界]
    E2 --> G
    E3 --> G
    F --> G
    G --> G1[完整剧情]
    G --> G2[剧情节点]
    G --> G3[事实卡]
    G --> G4[人物关系]
    G --> G5[未决问题]
    G --> H[角色来源对账]
    H --> H1[恢复原文人物]
    H --> H2[生成角色事件记忆]
    H --> H3[生成可说/隐瞒/未知边界]
    H --> I[角色行为画像]
    I --> J[写入案件专属知识节点]
    J --> J1[case:id/story 完整剧情]
    J --> J2[角色记忆节点]
    J --> J3[事件明细节点]
    G --> K[场景组合规划]
    H --> K
    K --> L[场景蓝图生成]
    L --> L1[训练目标]
    L --> L2[在场角色与主对话人]
    L --> L3[事实和剧情节点引用]
    L --> L4[开始/结束条件]
    L --> M[场景阶段剧本生成]
    M --> M1[接警或派警简报]
    M --> M2[现场第一印象]
    M --> M3[阶段目标和动作]
    M --> M4[考察点和完成条件]
    M --> N[角色/事实/训练闭环校验]
    N -->|通过| O[保存可发布案件与场景]
    N -->|失败| P[修复或规则回退]
    P --> N
```

## 2. 角色每轮生成流程

```mermaid
flowchart TD
    A[学员对话或执法动作] --> B[加载训练会话]
    B --> C[解析当前案件、场景、阶段和目标角色]
    C --> D[统一角色上下文编译器]
    D --> E1[强制读取案件完整剧情]
    D --> E2[读取角色专属事实账本]
    D --> E3[读取现场公开信息]
    D --> E4[读取短对话历史和累计摘要]
    D --> E5[读取动态状态与状态契约]
    E1 --> F[全局剧情一致性推理]
    E2 --> G[角色视角和披露边界过滤]
    E3 --> G
    E4 --> G
    F --> G
    G --> H{是否多角色场景}
    H -->|否| I[单角色提示词]
    H -->|是| J[导演选择发言角色和顺序]
    J --> K[逐角色提示词]
    K --> L[同场公开发言联动]
    I --> M[模型生成结构化回复]
    L --> M
    M --> N[角色事实依据校验]
    N --> O[身份和视角校验]
    O --> P[重复、元话语和学员复述清洗]
    P --> Q[状态契约后检]
    Q --> R[更新情绪/配合/风险/清晰度]
    R --> S[更新已公开事实和角色大脑]
    S --> T[阶段覆盖与安全条件判断]
    T --> U{满足阶段完成条件}
    U -->|否| V[返回角色台词并继续训练]
    U -->|是| W[阶段切换或结束训练]
```

## 3. 数据优先级与约束

```mermaid
flowchart LR
    A[完整剧情<br/>全局事实和因果基准] --> F[角色生成决策]
    B[角色事实账本<br/>本人知识边界] --> F
    C[本轮问题和公开信息<br/>当前回答目标] --> F
    D[场景与训练阶段<br/>当前任务范围] --> F
    E[动态状态和人物线<br/>表达方式与披露节奏] --> F
    F --> G[角色台词和行为]
    H[禁止虚构] -.硬约束.-> G
    I[禁止串戏和全知] -.硬约束.-> G
    J[禁止泄露未获知事实] -.硬约束.-> G
    K[必须优先回答本轮问题] -.硬约束.-> G
```

裁决优先级：

```text
完整剧情一致性
> 来源事实与确定性
> 角色本人知识边界
> 本轮问题和现场公开信息
> 当前场景与阶段
> 动态状态
> 人设表达风格
```

完整剧情的优先级用于判断事实是否一致；角色知识边界决定这些事实能否由当前角色说出口。
