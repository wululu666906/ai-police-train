# 训练大厅卡片视觉规范

## 页面结构

训练大厅采用紧凑型案件卡片陈列。页面背景使用浅色玻璃感底色和低饱和径向色晕，过滤区、任务区弱化传统实心白卡边界，统一使用半透明玻璃层。

- 页面内边距：桌面 `18px`，移动端 `12px`。
- 区块间距：`14px`。
- 卡片网格：`grid-template-columns: repeat(auto-fill, 420px)`。
- 卡片间距：`18px`。
- `960px` 以下网格切换为单列，卡片宽度 `100%`，最大宽度不超过视口。

## 案件卡片规格

案件卡片固定以“一个案件一张卡片”为粒度，不展示场景行列表。卡片点击主按钮后打开训练简报弹窗，在弹窗中选择具体训练场景。

- 固定宽度：`420px`。
- 移动端最大宽度：`calc(100vw - 32px)`，`480px` 以下为 `100%`。
- 高度：约 `298px`，移动端约 `292px`。
- 圆角：外层 `22px`，内部统计子卡 `14px`，按钮 `13px`。
- 内边距：桌面 `18px`，移动端 `16px`。
- 字号缩放：相对上一版统一缩小约 `6%`。

## 液态玻璃材质

卡片底层容器禁止使用整块纯色背景，统一采用淡彩液态玻璃。

- 主背景：`linear-gradient(135deg, rgb(255 255 255 / 74%), rgb(255 255 255 / 44%))`。
- 淡彩色晕：按 `case.id` 稳定分配 `--card-tint`，以 `radial-gradient` 方式叠加。
- 模糊参数：`backdrop-filter: blur(22px) saturate(180%)`。
- 边框：`1px solid rgb(255 255 255 / 62%)`。
- 内高光：`inset 0 1px 0 rgb(255 255 255 / 82%)`。
- 阴影：`0 18px 42px rgb(15 23 42 / 14%)`。
- 悬停：上移 `3px`，阴影增强到 `0 22px 48px rgb(15 23 42 / 18%)`。

## 卡片内容

卡片正文只保留案件必要信息和启动操作。

- 顶部：四列液态玻璃统计模块。
- 正文：案件类型、案件标题、案件背景摘要。
- 底部：主操作按钮。
- 禁止展示：
  - “核心要素待补充”
  - 预计用时
  - Solo / Scene Select / 是否单人

## 四列难度模块

难度标识区域是独立液态玻璃子卡片，单行四列等距排布。

| 列 | 标签 | 数据 |
| --- | --- | --- |
| 1 | 难度 | `primary_difficulty`，缺省归一化为“中” |
| 2 | 场景 | `scene_count` 或 `scenes.length` |
| 3 | 状态 | `statusLabel` |
| 4 | 日期 | `created_at` 格式化为 `YYYY-MM-DD` |

子卡参数：
- 高度：`56px`。
- 圆角：`14px`。
- 背景：`rgb(255 255 255 / 34%)`。
- 模糊：`blur(18px) saturate(160%)`。
- 标签字号：`10px`。
- 值字号：`13px`。

## 文本规则

- 案件类型：`11px`，单行截断。
- 案件标题：`24px`，单行截断。
- 案件摘要：`14px`，最多两行。
- 按钮文字：`15px`。
- 所有文本必须在 `420px` 边界内完成截断或换行，不允许撑宽卡片。

## 交互规范

- 卡片主按钮只打开现有 `TrainingBriefDialog`，不直接启动训练。
- 弹窗内选择场景后，确认按钮调用 `/training/start/{scene_id}`。
- 评估中的场景不可启动，沿用现有前端提示。
- 本规范不改变后端接口字段，不删除后端已有 `estimated_minutes` 等数据契约；只是卡片不展示这些字段。
