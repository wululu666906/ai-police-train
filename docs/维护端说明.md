# 维护端说明

## 本地入口

- 开发端口：`http://localhost:6670/`
- 单独启动命令：在 `frontend` 目录运行 `npm run dev:ops`
- 推荐本地开发启动命令：在项目根目录运行 `.\scripts\dev-restart.ps1`
- 后端仍使用现有 FastAPI 服务：`http://127.0.0.1:8000`

`.\scripts\dev-restart.ps1` 会同时启动：

- 后端 API：`http://127.0.0.1:8000`
- 管理端/学员端：`http://localhost:5556`
- 维护端：`http://localhost:6670`

## 默认维护账号

- 账号：`maintainer`
- 初始密码：`123456`
- 该账号仅在数据库中不存在同名账号时由后端启动初始化创建。

生产环境首次登录后必须立即重置维护账号密码，并妥善保管维护端访问入口。

## 权限边界

- `maintainer`：可进入维护端，管理 `admin` 和 `student` 账号。
- `admin`：只能进入现有管理端，不可访问维护端接口。
- `student`：只能进入学员端，不可访问维护端接口。

维护端默认不开放创建新的 `maintainer` 账号，避免维护权限扩散。

## 文件导入账号

账号管理页提供“文件导入”入口，采用“上传预览 -> 确认导入”的两步流程，避免文件一上传就直接写库。

支持格式：

- 推荐：`.xlsx`、`.csv`
- 可用：`.tsv`、`.json`、`.docx` 表格、`.ods`、文本型 `.pdf`、`.txt`
- 老式 `.xls` 暂不直接解析，建议另存为 `.xlsx`

推荐表头：

```csv
username,password,role,display_name,real_name,phone,email,unit,department,bio
```

字段规则：

- `username` 必填
- `password` 不填时默认 `123456`
- `role` 只能是 `admin` 或 `student`
- 文件导入不允许创建 `maintainer`
- 已存在账号和文件内重复账号会在预览中标记出来
