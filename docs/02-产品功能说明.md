# AI虚拟警情处置模拟训练平台 — 产品功能说明

**版本**：v1.0（对应当前代码实现）  
**目标用户**：警校生、培训民警（学员端）；教官、教务管理员（管理端）

---

## 一、产品概述

平台提供 **管理端（admin）** 与 **学员端（student）** 两套界面，围绕「案件 → 训练场景 → 对话训练 → 评估复盘」主流程设计。学员在模拟场景中扮演民警，与 AI 扮演的报警人、嫌疑人、证人等进行多轮对话；训练结束后系统生成**多维度评分与改进建议**。

---

## 二、用户角色

| 角色 | 账号示例 | 权限 |
|------|----------|------|
| 管理员/教官 | `admin` | 案件、场景、角色、知识库、学员、数据质量、仪表盘 |
| 学员 | `student001` 等 | 训练大厅、对话训练、历史记录、评估查看 |

*默认演示密码见系统初始化配置（通常为 `123456`，生产环境须修改）。*

## 三、学员端功能（警校生 / 培训民警）

### 3.1 训练大厅（`/student/hall`）

- 浏览已发布的训练案件与场景。  
- 按案件类型、难度筛选，进入对应训练。  
- 展示训练入口说明与场景简介。

### 3.2 对话训练（`/student/training/:id`）

核心训练页面，主要能力包括：

| 能力 | 说明 |
|------|------|
| **多轮对话** | 学员输入处置用语，AI 按角色人设回复 |
| **阶段推进** | 显示当前训练阶段（如初始接触、信息收集等） |
| **多角色同场** | 同一场景可配置多名 AI 角色，按导演逻辑发言 |
| **接警简报** | 查看案件背景、现场信息摘要 |
| **推荐问句** | 系统根据阶段与覆盖情况推荐可追问方向 |
| **语音输入** | 支持 Web 语音 / 讯飞 ASR（按环境配置） |
| **结束训练** | 主动结束并触发评估生成 |

**训练体验设计要点**（来自 UX 方案）：

- 对话区采用即时通讯布局，区分「学员（警察）」与「AI 角色」气泡。  
- AI 分轮释放信息，避免一次说完案情。  
- 情绪、对抗、隐瞒等行为由后台角色参数与场景引擎控制。

### 3.3 训练历史（`/student/history`）

- 查看个人训练记录列表。  
- 区分进行中 / 已完成会话。  
- 支持查看会话详情与评估入口。

### 3.4 评估结果（`/student/evaluation`）

训练结束后展示：

- **总分**及分项得分。  
- **评分维度**（与提示词设计一致）：  
  - 执法语言规范性  
  - 执法流程完整性  
  - 法律依据正确性  
  - 情绪控制能力  
  - 信息获取效率  
- **优点、不足与改进建议**（结合对话内容）。

## 四、管理端功能（教官 / 管理员）

### 4.1 仪表盘（`/admin/dashboard`）

- 训练与学员活跃情况概览。  
- 为教务管理提供宏观数据入口。

### 4.2 案件与场景中心（`/admin/cases`）

**核心内容生产模块**，主要功能：

| 功能 | 说明 |
|------|------|
| 案件列表 | 查询、筛选、发布状态管理 |
| 结构化录入 | 案件名称、类型、背景、人物、冲突点、关键/隐藏事实 |
| 文本/笔录导入 | 支持普通文本或笔录文件，AI 辅助解析为结构化数据 |
| 场景生成 | 一个案件可配置多个训练场景（接警、现场询问等） |
| 场景编辑 | 阶段目标、难度、到场角色、主对话人、训练提示文案 |
| 场景角色校验 | 检测主对话人缺失、角色分配不合理等问题 |
| 发布训练 | 发布后学员端可见 |

**支持的案件类型（示例）**：邻里纠纷、打架斗殴、酒驾、盗窃、诈骗、群体性事件等。

### 4.3 角色库（`/admin/roles`）

- **公共角色模板**：配合型、情绪型、对抗型、隐瞒型等预置人设。  
- **案件专属人物**：绑定具体案件，参与场景训练。  
- 可配置：情绪、信任度、配合度、说话风格、是否隐瞒信息等。

### 4.4 知识库（`/admin/knowledge`）

- 上传与管理法律、案例、执法规范、话术等文档。  
- 支持检索测试，为 RAG 提供专业知识约束。  
- 降低 AI 对话「背错法条」或脱离规范的风险。

### 4.5 学员管理（`/admin/students`）

- 学员账号维护、批量导入（按实现）。  
- 查看学员训练活跃情况。

### 4.6 数据质量（`/admin/data-quality`）

- 巡检历史训练数据、异常分值、乱码等问题。  
- 配合后端清理脚本维护数据一致性。

### 4.7 个人中心（`/admin/profile`）

- 管理员个人信息与密码等（按页面实现）。

## 五、核心业务流程

```
教官：创建/导入案件 → 结构化校对 → 生成/编辑场景与角色 → 绑定知识库 → 发布
                                    ↓
学员：登录 → 训练大厅选场景 → 多轮对话训练 → 结束训练
                                    ↓
系统：保存对话记录 → 多维度 AI 评估 → 学员查看复盘 → 可再次训练
```

---

## 六、MVP 验收标准（产品侧）

参考项目 UX 与开发方案，试点阶段建议关注：

1. **AI 像真人**：不一次说完、有情绪与逻辑、至少可持续 5 轮以上有效对话。  
2. **回答专业**：不胡乱引用法条，关键处置建议与知识库一致。  
3. **评估有用**：每个维度有得分原因，而非空泛评语。  
4. **教官效率**：从新建案件到发布训练，熟练后 ≤30 分钟。  
5. **学员易用**：首次进入无需长培训即可完成一次完整训练。

| 调研中的需求 | 产品功能映射 |

| 执法向反馈 | 五维评估 + 改进建议 |
