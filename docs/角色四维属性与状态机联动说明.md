# 角色四维属性与状态机联动说明

## 1. 四维属性定义

| 属性 | 指标释义 | 对角色行为、对话与决策的影响 |
| --- | --- | --- |
| 情绪 `emotion` | 当前唤醒度、压力和激动程度，越高越激动 | 仅轻微影响语速和语气强弱 |
| 配合度 `cooperation` | 当前互动姿态的反馈值 | 仅轻微影响措辞礼貌程度 |
| 风险 `risk` | 当前警觉和失控风险反馈值 | 仅轻微影响警觉语气 |
| 清晰度 `clarity` | 当前表达组织反馈值 | 仅轻微影响句式完整度 |

四维值范围统一为 `0-100`。四维值不得改变角色是否发言、事实权限、披露范围、动作结果或训练阶段。

## 2. 初始化规则

角色构建节点在生成人物画像时同步生成四维初始值。平台持久化该值，场景节点只继承，不重复生成。存量数据继续由初始化服务兼容读取。

1. 人工明确配置值。
2. 角色构建节点生成值。
3. 存量角色字段兼容值。
4. 稳定身份散列的中性兜底值。

同类角色会根据稳定身份散列获得 `-4` 至 `+4` 的确定性微调，以避免全员同值，同时保证同一角色重复初始化结果一致。存量回填仅处理缺失值和遗留默认值；明确人工值不覆盖，已开始会话的运行时快照不参与迁移。

## 3. 表达控制权重

TinyTroupe 将四维值转换为轻量语言提示，不计算综合控制权重。人物画像决定主要语言风格，四维值只对语速、措辞强弱、警觉感和句式完整度做小幅调整。事实边界始终独立且优先。

## 4. 数值驱动规则

每轮先由可审计的学员问法、处置动作、场景刺激和人物修正规则计算变化，再写入角色快照。普通单轮各轴最大变化为 `±12`；明确的降级、安抚和紧急安全处置可按现有影响规则使用例外上限。

处理顺序为：装载 TinyWorld -> 在场角色感知输入 -> 在场角色进入 TinyTroupe 行动 -> 聚合事实审计 -> 计算四维反馈 -> 原子持久化世界与平台状态。TinyTroupe 认知状态产生的 `state_delta` 每轴先裁剪到 `±4`，与确定性规则合并后仍执行单轮 `±12` 上限。

## 5. 混合状态机

角色四维混合状态按以下优先级判定：

1. `crisis`：风险达到危机阈值。
2. `confused`：清晰度低于混乱阈值。
3. `resistant`：配合度低于抵触阈值。
4. `agitated`：情绪达到激动阈值。
5. `engaged`：配合度和清晰度支持有效互动。
6. `guarded`：其余防备、观望状态。

状态切换采用 `5` 点滞回：进入阈值和退出阈值相差 5 点，避免数值在边界附近造成状态反复抖动。状态标签只控制轻量口吻并用于界面反馈。

## 6. 两类状态机的调用关系

训练阶段状态机管理“当前处置进行到哪一步”，依据阶段目标、必做动作和评估点推进。角色四维混合状态机管理“人物此刻如何反应”。两者独立持久化，在每轮对话中由训练运行时统一调用。

四维混合标签仅用于界面反馈和轻量语气提示。训练阶段只依据考核点、动作和完成规则推进，不受四维标签阻断。

## 7. 对话上下文与开场

开场角色的四维快照和常规对话使用同一初始化来源。训练开始后，只有本场景在场角色进入持久化 TinyWorld；每轮在场角色接收学员输入和其他角色的公开 `TALK`，由 TinyTroupe 世界自行决定谁发言。

普通已知事实可以直接回答；`secret=true` 默认永久禁止。隐瞒事实只依据阶段、直接追问、前置事实和显式披露策略判断，不读取四维状态。TinyTroupe 只能看到本轮可回答集合，聚合审计失败时对应角色重试一次，仍失败则整轮不提交。

场景开场通过 `opening_config` 配置开关、动态或预设模式、最多三名有序角色、导演约束与预设台词。开场消息写入消息表并记录 `opening_message_ids`，`opening_delivered` 保证恢复或刷新会话时不会重复生成。
# 场景级初始化与对话记忆（2026-08）

## 场景角色状态优先级

训练运行时优先读取 `scene_roles.initial_state`。该 JSON 保存情绪、配合度、风险和表达清晰度，以及生成来源、规则版本、输入摘要哈希和生成时间。角色表中的旧四维字段只用于旧数据兼容，不再作为场景训练的首选来源。

新建或重建案件时，角色构建节点根据本人记忆和人物画像生成初始值，场景只继承并持久化。旧数据库在启动兼容迁移中继续使用现有字段确定性回填，不调用外部模型。

## 会话上下文

`messages` 表按 `created_at, id` 保存从开场到结束的完整公开原文，是平台审计与恢复的事实源。AI 服务同时保存版本化 TinyWorld 快照，其中包含角色认知和情景记忆；私有思考不会写入平台消息表。

服务重启、缓存缺失或消息水位不一致时，系统直接从完整消息表重建上下文。其他角色的公开台词可作为现场信息，但不会进入当前角色的本人记忆。
